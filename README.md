# Pureun-frontend

푸른구 국민체육센터 시설 대관 시스템의 **프런트엔드**(Next.js)입니다. 가상 고객 인터뷰를 바탕으로 만든 실습 프로젝트이며, 실제 기관과 관련이 없습니다.

백엔드 저장소: [Pureun-backend](https://github.com/midayo13-droid/Pureun-backend)

> 백엔드가 Render 무료 서버라서 **오래 쓰지 않으면 잠들고, 첫 접속에 30초~1분쯤 걸릴 수 있습니다.** 처음에 데이터가 안 나오면 잠시 뒤 새로 고침해 주세요.

## 확인용 계정 (가상 데이터)
| 구분 | 휴대전화 번호(아이디) | 비밀번호 | 설명 |
|---|---|---|---|
| 관리자 | `0105550000` | `Admin#2026!` | 대관 담당자(오주무관). 로그인하면 관리자 화면(`/admin`)으로 이동 |
| 일반(신청자) | `0105550001` ~ `0105550050` | `Demo#2026!` | 단체 대표자 계정 50개. 예) `0105550001` 푸른 풋살클럽, `0105550002` 청솔 배드민턴동호회 |

- 이 계정은 시연용 **가상 계정**입니다. 실제 개인정보가 아닙니다.
- 회원가입 화면의 휴대전화 인증번호는 시연용 고정값 `123456`입니다. 실제 문자는 발송되지 않습니다.
- 접수 중인 기간(다음 달 이용분)은 시드 데이터를 넣은 시각 기준으로 만들어집니다. 마감이 지나면 관리자 화면의 **추첨 관리**에서 마감 시각을 고치거나 시드를 다시 실행하세요.

## 화면
| 구분 | 화면 |
|---|---|
| 신청자(모바일·PC) | 메인, 회원가입, 로그인, 시설·시간 현황, 신청서, 내 신청·결과, 규정 안내(Q&A) |
| 관리자(PC) | 대시보드, 신청 관리(방문 신청 대리 입력), 감면 증빙 검토, 추첨 관리, 추첨 기록, 이용 불가일, 통계, 이용 이력 |

신청자 화면은 모바일에서는 하단 탭, PC에서는 상단 메뉴로 이동합니다.

## 기술 스택
Next.js 16 (App Router), React 19, TypeScript. 별도 UI 라이브러리 없이 직접 만든 CSS를 씁니다. 배포는 Vercel을 기준으로 합니다.

## 환경 변수
| 이름 | 뜻 | 필수 | 예시 |
|---|---|---|---|
| `NEXT_PUBLIC_API_URL` | 백엔드 API 주소(맨 끝에 `/api`까지 포함). 브라우저에서 이 주소로 직접 요청합니다 | 필수 | `https://pureun-backend.onrender.com/api` |

로컬 개발에서는 `.env.local`에 `NEXT_PUBLIC_API_URL=http://localhost:4000/api`를 넣습니다(값이 비어 있는 예시는 `.env.example`). `NEXT_PUBLIC_`로 시작하는 값은 브라우저에 공개되므로 **비밀 값을 넣지 마세요.**

## 내 컴퓨터에서 실행
```bash
npm install
cp .env.example .env.local   # NEXT_PUBLIC_API_URL을 채웁니다
npm run dev                  # http://localhost:3000
```
백엔드(`Pureun-backend`)가 먼저 실행 중이어야 합니다.

## Vercel에 올리기
1. Vercel에서 **Add New → Project**로 이 저장소를 가져옵니다.
2. Framework Preset은 **Next.js**(자동 인식), Build Command는 기본값 `npm run build`, Root Directory는 저장소 최상위 그대로 둡니다.
3. **Environment Variables**에 `NEXT_PUBLIC_API_URL`을 넣습니다(Render 서버 주소 + `/api`).
4. 배포한 뒤 Vercel 주소를 백엔드의 `CORS_ORIGIN`에 넣고 백엔드를 다시 배포(재시작)합니다. 그렇지 않으면 브라우저가 백엔드 요청을 막습니다.
